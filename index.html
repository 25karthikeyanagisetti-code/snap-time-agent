What we're trying to do

Modern AI optimizes correctness. People do something stranger — we hesitate, forget, forgive, and sometimes choose the wrong thing on purpose because of how we feel and what we remember. This project asks: what minimum extra structure does an LLM-style agent need to behave like that?

01

Emotion as state

A 5-dimensional vector — survival, guilt, loyalty, fear, curiosity — that updates every step and tilts the agent's decisions.

02

Memory that ages

Episodic memories with decay, importance, emotional charge, and similarity-based reactivation. Old wounds quietly weaken; relevant context wakes them.

03

Bounded thinking time

A "Snap Time" window — the agent has to decide before it expires. Hesitation has a real cost.

04

Find the failure modes

Then sweep the parameters and find the regimes where the agent paralyzes, forgets too fast, or commits irreversibly. So far we have three named failure modes.

The equation, in pieces

Standard ML loss on the left. Three new terms on the right — emotion-weighted decision pressure, episodic memory impact, and a Snap Time deliberation horizon.

$\theta^* = \arg\min_{\theta}\; \mathbb{E}_\tau\!\left[\sum_{t=0}^{T_{\text{snap}}}\!\left(\;\underbrace{\mathcal{L}(f_\theta(x_t),y_t)}_{\text{task loss}}\;+\;\underbrace{\Phi(v(s_t,a_t),e_t)}_{\text{decision pressure}}\;+\;\underbrace{\lambda\cdot\mathrm{MemoryImpact}_t}_{\text{memory bias}}\right)\right]$
$\Phi(v,e_t)$ — emotion-weighted decision pressure
$\mathrm{MemoryImpact}_t$ — aging episodic recall
$T_{\text{snap}}$ — bounded autonomy window
$e_t \in [0,1]^5$ — emotion vector

Snap Time $T_{\text{snap}}$

$t \in [0, T_{\text{snap}}]$

The agent has $T_{\text{snap}}$ steps to act before the world moves on. Hesitation costs steps. The partner in our sandbox dies if the agent doesn't reach them in 7 steps — so $T_{\text{snap}}$ governs whether commitment is even possible.

12
More time means more chances to commit, but the Paralysis Valley never fully vanishes — even at T=20, a residual 63% failure peak persists.

Decision pressure $\Phi(v, e_t)$

Additive: $\Phi = -v + \kappa \langle e, c\rangle$

For each candidate action, $\Phi$ combines its task value $v$ with how much the action conflicts with the agent's current emotion. Lower $\Phi$ wins. $\kappa$ controls how loud the emotion is in the decision.

What we've found so far

Eight sweeps. 80,800 episodes. Three named failure modes. Full data and code in the repo.

Wave 1

The Paralysis Valley

Failure rate is non-monotonic in emotion weight. Weak emotion paralyzes the agent more than no emotion or strong emotion. Worst point: 98% failure at κ ≈ 0.25.

Wave 2

The Forgiveness Tradeoff

Aging the memory rescues the agent from paralysis — and ALSO strips out commitment. There's no preage where you both escape paralysis AND keep the capacity to commit. Forgetting the wound costs the lesson.

Wave 2

No-free-lunch across Φ

Four different couplings (additive, multiplicative, max, log-sum-exp) — each has a distinct pathology. None give both no-paralysis AND robust rescue. The trade-off appears intrinsic.

Wave 3

The Homogenization Collapse

In chained episodes with carried memory, the committed-rescuer regime collapses within ONE episode of outcome encoding. All initial conditions converge to the same failure attractor. No behavioral types emerge from experience.
